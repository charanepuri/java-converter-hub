# Converter Hub
 
## Project Description
A command-line collection of commonly used conversion utilities. Users select a conversion category, choose the source and destination units, enter a value, and receive the converted result without opening separate tools.
 
## Technology Stack
Java (JDK), OOP, Scanner, methods, switch statements/expressions, BigDecimal or suitable numeric types, and exception handling.
 
## Features
- Provide a menu for length, weight, temperature, and time conversions.
- Convert values between supported units within each category.
- Validate numeric input and selected units.
- Display results with readable units and suitable precision.
- Allow users to perform multiple conversions in one session.
- Optionally maintain a recent conversion history.
 
## Database Design
No database is required. Conversion formulas and supported units can be defined in Java code or stored in configuration files. If conversion history is implemented, it can be stored in memory or a local file; a database is unnecessary for the core functionality.
 
## Learning Outcomes
- Implement mathematical conversion formulas.
- Use methods to make conversion logic reusable and testable.
- Apply switch statements or maps to select conversion rules.
- Validate numeric input and handle invalid values.
- Understand precision and rounding when displaying results.
 
## Explanation
The program displays conversion categories and asks the user to select one. It then collects the input value and unit choices, applies the appropriate conversion formula, and prints the result. Each conversion type can be implemented in a separate method so that the code remains organized and easier to extend.
 
## Conclusion
Converter Hub is a practical exercise in Java fundamentals and problem-solving. It reinforces arithmetic, conditional logic, reusable methods, input validation, and clean console interaction.
